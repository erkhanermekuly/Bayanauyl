# Баянауыл — каменная сказка Сарыарки

Сайт-путеводитель по Баянаульскому национальному парку (Павлодарская область, Казахстан): озёра, скалы и легенды, природа, сезоны, маршруты и галерея.

## Как устроен

Статический сайт без сборки: `index.html`, `css/style.css`, `js/main.js`, фотографии в `images/`. Чтобы посмотреть локально, достаточно открыть `index.html` в браузере.
